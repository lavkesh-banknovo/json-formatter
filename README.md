# JSON Formatter & Converter

Browser-based JSON formatting and conversion tool with PII redaction, multi-format export, and live preview.

## Features
- Format, Minify, Validate JSON
- Convert to XML, YAML, CSV, TSV
- Download in multiple formats
- PII redaction (SSN/EIN auto-masked)
- Dark/Light theme, drag & drop upload
- Collapsible tree view with syntax highlighting
